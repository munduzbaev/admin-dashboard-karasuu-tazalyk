# Тазалык Кара-Суу - Панель администратора

Это панель администратора и управления (CRM / Dashboard) для муниципальной службы "МП Тазалык Кара-Суу".

## Запуск локально

1. Установите все зависимости проекта:
   ```bash
   npm i
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
